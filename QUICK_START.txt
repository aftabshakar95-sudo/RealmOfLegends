🚀 DEPLOYMENT STEPS:

1. CREATE FREE ACCOUNT (2 minutes):
   
   → Go to: https://render.com
   → Click "Get Started for Free"
   → Sign up with GitHub (easiest) or email
   → NO CREDIT CARD REQUIRED!

2. CREATE DATABASE (3 minutes):
   
   → Click "New +" → "PostgreSQL"
   → Name: realmoflegends-postgres
   → Region: Oregon (US West)
   → Plan: Free
   → Click "Create Database"
   → Wait 1-2 minutes

3. CREATE WEB SERVICE (3 minutes):
   
   → Click "New +" → "Web Service"
   → Click "Connect GitHub"
   → Select: RealmOfLegends repository
   → Click "Connect"
   
   Configure:
   → Name: realmoflegends
   → Region: Oregon (US West)
   → Runtime: Docker
   → Instance: Free
   → Click "Create Web Service"

4. CONNECT DATABASE (2 minutes):
   
   → Go to your Web Service dashboard
   → Click "Environment" tab
   → Add environment variable:
     • Key: ConnectionStrings__DefaultConnection
     • Value: [Copy "Internal Database URL" from PostgreSQL dashboard]
   
   → Add these too:
     • ASPNETCORE_URLS = http://0.0.0.0:8080
     • ASPNETCORE_ENVIRONMENT = Production

5. DEPLOY!
   
   → Click "Manual Deploy" → "Deploy latest commit"
   → Wait 5-10 minutes (first deploy is slower)
   → Watch the build logs

6. YOUR GAME IS LIVE! 🎮
   
   → URL: https://realmoflegends.onrender.com
   → Login: https://realmoflegends.onrender.com/Account/Login
   → Click the URL to play!
