🔧 Technical Implementation

Frontend: Pure JavaScript (ES6+) with async/await for battle flow control

Animations: CSS3 keyframe animations with transform and opacity

Architecture: Event-driven system with promise-based timing

Backend: ASP.NET Core MVC with Entity Framework for persistence
